# Feldspath
Le but de ce projet est de réaliser un robot télécommandé naviguant dans des endroits inaccessibles pour les humains afin de repérer les victimes d’un accident de chantier ou des dangers potentiels.

Ce robot disposera d’équipement comme une lampe torche, un haut parleur pour permettre aux secouristes de communiquer avec les victimes et de les repérer grâce à un signal sonore.

Le robot servira également à prendre et afficher des photos de son environnement sur commande de l’utilisateur.

Il sera, comme indiqué précédemment,  équipé d’une lampe torche frontale permettant d’éclairer les endroits sombres ainsi que d’un capteur de gaz servant à détecter les zones à risques.

Fonctionnalitées : 

Se déplacer dans un terrain accidenté
Contrôler le robot via application
Application téléphone télécommande + retour vidéo
Retour vidéo du robot et de son environnement.
Capture d’image
Galerie de photo et les stocker sur le serveur
Communication entre robot, téléphone et serveur pour la prise d’image et la consultation de la galerie
Détection de gaz et mesures
Accès aux mesures, avec date, heure et localisation
Émettre un signal sonore

Matériel : 
Carte Arduino ( Arduino MKRIoTCarrier Rev 2)
Mbot + module camera ESP-32
Module capteur de gaz (potentiellement MKRIoT)
Lampe torche / lumière
Chenilles pour le Mbot
